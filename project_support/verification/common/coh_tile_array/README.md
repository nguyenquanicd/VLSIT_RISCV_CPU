`m_vlsit_riscv_coh_tile_array` connects one ownership/grant adapter per hart to the shared MESI coherence fabric. PREPARE stays blocked while the cache reports same-line refill activity; accepted PREPARE owns a tag/line lock through successful COMMIT or ABORT. This module integrates the control path only. It does not instantiate CVA6, HPDcache arrays, LLC, or AXI data paths.

The directed test exercises a cold exclusive grant, then a second hart sharing the same line. It stalls PREPARE with the cache busy query, checks the tagged lock and same-line exclusion, completes the two-phase E-to-S transition, and checks the shared grant and lock release. It also accumulates the fabric PMU taps and checks the exact two-request counts for accepted requests, directory hit/miss, PREPARE/COMMIT ACK, and grants, plus a nonzero same-line-lock stall event. It runs at both 2 and 4 harts.

Run lint with `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_lint.ps1` or run the 2/4-hart simulation with `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_regression.ps1`. Regression logs are written under `verification/non_coherence_cluster/reports/full_integration/`; each run creates a fresh temporary C++ build directory under `C:\HQuan\.test_tmp\riscv_coh_tile_array_<harts>_<timestamp>` to avoid reusing generated code from a different parameter value. The script compiles the Verilator model directly with MinGW because the local MSYS `make` bootstrap is blocked by a Windows named-object permission error.

`m_vlsit_riscv_coh_tile_array` nối một adapter request/grant cho mỗi hart với fabric coherence MESI dùng chung. PREPARE bị giữ khi cache báo refill cùng dòng; PREPARE được nhận sẽ giữ khóa tag/dòng đến khi COMMIT hoặc ABORT thành công. Module chỉ tích hợp đường điều khiển; chưa instantiate CVA6, mảng HPDcache, LLC hay đường dữ liệu AXI.

Test directed cấp quyền exclusive lạnh, sau đó cho hart thứ hai chia sẻ cùng line. Test tạo stall PREPARE bằng tín hiệu cache-busy, kiểm tra tag/line lock và chặn truy cập cùng dòng, hoàn tất chuyển trạng thái E-to-S hai pha, rồi kiểm tra grant shared và nhả khóa. Test còn tích lũy tap PMU từ fabric và kiểm tra chính xác tổng hai request cho request được nhận, directory hit/miss, PREPARE/COMMIT ACK và grant, đồng thời xác nhận event stall cùng line khác 0. Test chạy với cả 2 và 4 hart.

Chạy lint bằng `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_lint.ps1` hoặc mô phỏng 2/4 hart bằng `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_regression.ps1`. Log nằm trong `verification/non_coherence_cluster/reports/full_integration/`; mỗi lần chạy tạo thư mục C++ tạm mới tại `C:\HQuan\.test_tmp\riscv_coh_tile_array_<harts>_<timestamp>` để tránh dùng code sinh từ cấu hình tham số khác. Script biên dịch model Verilator trực tiếp bằng MinGW do lệnh khởi tạo MSYS `make` tại máy này bị chặn bởi quyền Windows named-object.
