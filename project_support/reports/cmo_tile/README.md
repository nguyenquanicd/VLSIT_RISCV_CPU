Run `python scripts/lint_cmo_tile.py` from the project root. Twelve standalone configurations pass Verilator lint with zero errors and zero warnings: CMO at 2/4 harts × 2/5/8/16 contexts, and tile adapter with its real lock-table child at 2/5/8/16 contexts. Commands and full output are saved per configuration. `rules.txt` records zero mechanical errors and two naming warnings for HDS-compatible `error` port spellings. No simulation, formal proof, synthesis or full-cluster lint success is claimed. / Chạy lệnh trên từ gốc dự án. Mười hai cấu hình đạt lint không lỗi/cảnh báo. Rule check có hai cảnh báo tên port giữ đúng HDS. Chưa mô phỏng, formal, synthesis hoặc lint thành công toàn cluster.

The CMO module accepts one resolved CBO, requests preparation using the CCU's shared context, invokes LLC maintenance only after successful preparation, then requests COMMIT or ABORT. It reports completion only after CCU finish completion. PC, virtual address, hart and error remain associated with the command. Same-edge endpoint request/completion is supported. True INVAL suppresses owner writeback. / CMO dùng context CCU hiện có, chỉ gọi LLC sau PREPARE thành công, chờ COMMIT/ABORT hoàn tất mới báo done và giữ nguyên metadata lệnh.

The tile adapter buffers ownership requests and grants independently, allowing same-edge consumption and replacement. Probe metadata is preserved, and PREPARE admission now reserves a local line lock using `m_vlsit_riscv_cache_line_locks`. Successful terminal response handshakes release matching locks. Native access/victim query enforcement, MESI metadata and cache-array arbitration still require source integration. / Adapter đã có khóa local cho PREPARE đến ACK terminal, giữ nguyên metadata; vẫn cần nối query vào native cache và triển khai MESI/array arbitration.

The latest matrix includes 5 contexts to exercise a non-power-of-two tag space: 12 configurations total, with zero lint errors/warnings. / Ma trận mới có thêm 5 context để kiểm tra độ rộng tag không phải lũy thừa hai: tổng 12 cấu hình, không lỗi/cảnh báo lint.

These modules define integration service boundaries. The CCU fabric, native CVA6 retirement changes, HPDcache probe/MESI changes and LLC per-line maintenance still need implementation before the top can elaborate. / Các module này mới định nghĩa biên dịch vụ tích hợp; còn thiếu implementation của các endpoint trước khi TOP có thể elaborate.
