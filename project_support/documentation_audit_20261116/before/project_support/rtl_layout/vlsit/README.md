## English

This directory contains new VLSIT-authored modules and CSR RTL generated from the approved workbook. `csr_generated/` is tool output; edit its workbook or generator source and regenerate it instead of editing generated RTL.

The available blocks cover AXI4-Lite decode and LLC RegBus conversion, PMU, debug routing, address-region decode, CVA6 PMA/tile wrappers, coherence transaction tracking, a four-bank sharer directory, per-bank round-robin arbitration, tagged probes, the tile adapter array, AXI4+ATOP memory mux, LLC wrapper, and LLC-to-memory width adapter. The cluster core now composes these blocks under the AXI top. Full CPU-to-memory simulation and functional verification remain open.

The VLSIT rule check reports no rule errors; generated CSR has one justified HIE-02 warning. Verilator lint passes for the bank arbiter with 5, 8, and 16 transaction slots. Some AXI4-Lite targets have unused `PROT` fields because their register-side protocol has no protection fields.

The memory mux `m_vlsit_riscv_axi_mem_mux.sv` reuses the pinned PULP `axi_mux` unchanged. It extends 4-bit tile IDs to 6 bits, preserves AWATOP, and routes B/R responses to the source hart. Lint passes for 2 and 4 harts with 0 errors and 27 upstream/adapter warnings; the rule check has 0 errors and one intentional HIE-02 warning. Directed Verilator simulation passes for both hart counts. Run `python scripts/sim_axi_mem_mux.py`; results are in `verification/common/reports/axi_mem_mux/`. This module is not yet connected to the cluster core or LLC.

The width adapter `m_vlsit_riscv_axi_dw_adapter.sv` reuses pinned PULP `axi_dw_converter` without changing its RTL or license. It maps the LLC's fixed 64-bit AXI4+ATOP port to parameterized 32/64/128/256-bit external memory data widths and is instantiated in the integrated core/top hierarchy. The VLSIT rule checker reports 0 errors and one intentional HIE-02 warning. Verilator lint and directed simulation pass at all four widths, including B/R ID and SLVERR propagation; 128/256-bit read data coverage is limited to one aligned 64-bit transfer per wide beat. Full-cluster width-profile simulation remains open. Run `python scripts/sim_axi_dw_adapter.py`; logs are in `verification/common/reports/axi_dw_adapter/`.

## Tiếng Việt

Arbiter giữ slot đã chọn ổn định đến khi được nhận; các bank độc lập có thể cấp grant đồng thời.
