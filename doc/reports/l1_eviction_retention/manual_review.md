# Manual review / Kiểm tra thủ công

- DEC-036: origin-00 completion line must match the retained victim before release; the native flush engine already checks the full response ID and consumes B with READY high. An error consumes transport but does not authorize a directory update or replacement.
- Stage-2 metadata is captured on admission, not recaptured during hold/refill/flush stalls. Actual MSHR VALID follows the executed CS; the miss handler does not treat CS as allocation enable. The resident tag and data remain untouched until successful B.
- Pending victim and replacement line both participate in the existing probe-busy query. Admission/replay pauses; already issued refills can arbitrate during hold and use the existing refill-busy priority. Fatal failure keeps the context until reset.
- Ordinary failure has a reset-only interrupt source; generic diagnostics retain W1C. Generated CSR RTL/workbook are unchanged. Detailed source/address record remains A-06.
- LLC pending entries cover every miss. Full-table admission therefore gates every miss, while a completed oldest entry can still commit/free capacity. The directed unit covers clean-full, dirty-full, completion escape, failed refill and pointer wrap. CCU victim-child capacity is a different A-05 issue.
- No external port, parameter, hierarchy or technology cell changed. No new signed/2-state signal, package, macro, latch or unsynthesizable production process was introduced. The VLSIT core uses logic, a generate decode and always_ff with comma-separated events. Native licensed copies keep upstream layout/names per the user's explicit rule.
- New code retains original license/copyright; dated history names Quan Nguyen and Codex - VLSI Technology page. Before snapshots and SHA-256 support comparison. Rule checker baseline/final both retain the same six existing core warnings; no new rule error is accepted.
- Testbench expectations come from TEST-050 data values and DEC-036 fault/reset rules. SRAM/tag access is read-only; injection changes only AXI response behavior. Both commit ports are observed. Backpressure changes at the falling edge, avoiding a same-edge BFM sampling race. Native RTL warnings remain fatal; no warning-disable flag was introduced.
