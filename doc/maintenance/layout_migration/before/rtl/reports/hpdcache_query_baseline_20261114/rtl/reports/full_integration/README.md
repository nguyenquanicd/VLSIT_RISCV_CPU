The HDS records this mapping under the probe scheduler definition. / Context và scheduler đã truyền bit cho phép ghi trả PREPARE để phân biệt FLUSH và true INVAL, đúng REQ-MEM-015. Bit giữ ổn định cùng request và bằng 0 ở COMMIT/ABORT.

The tag directory and data array each use a shared single-request RAM control path with fixed-priority arbitration in the licensed HPDcache source. A correct probe implementation must add a tagged cache-side request/response path, coordinate lookup and data reads with the CPU/refill/flush/error users, and provide explicit stall/replay when the probe owns an array cycle. PREPARE must preserve the line's stable MESI state through its matching COMMIT or ABORT; a dirty-M PREPARE must use the existing owner writeback path and return the matching AXI B status before ACK. No native probe RTL has been added yet.
