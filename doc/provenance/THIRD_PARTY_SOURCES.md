# Third-party source provenance / Nguồn gốc mã nguồn bên thứ ba

Licensed source copies used by this project are committed under `rtl/common/third_party` and related verification directories. The local upstream Git checkout metadata remains on the workstation and is excluded from the project index to avoid accidental embedded repositories. This file records the checked-out source identities.
