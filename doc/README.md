Each design keeps its editable diagrams, FSMs, waveforms, register sources and references alongside the specification. The cluster folder also includes architecture, source provenance, research and design reviews used to develop its specification.

Mỗi thiết kế giữ sơ đồ có thể chỉnh sửa, FSM, waveform, nguồn thanh ghi và tài liệu tham chiếu cạnh đặc tả. Thư mục cluster còn có kiến trúc, nguồn gốc IP, nghiên cứu và review phục vụ đặc tả.

Implementation reports, raw tool output, obsolete figures, historical snapshots, vendor documentation and licenses are in [project_support](../project_support/README.md). [Project layout / Cấu trúc dự án](PROJECT_LAYOUT.md).

Báo cáo triển khai, output công cụ, hình cũ, snapshot, tài liệu vendor và license nằm trong `project_support`.
