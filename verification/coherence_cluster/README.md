# verification/coherence_cluster — External ACE profile (reserved) / Profile ACE bên ngoài (dự phòng)

Reserved for the verification of a future cluster TOP that is coherent with agents outside it through AMBA ACE. The matching RTL folder [`rtl/coherence_cluster`](../../rtl/coherence_cluster/) is not implemented, so this folder is intentionally empty.

Dành cho kiểm chứng TOP cluster tương lai có coherence với agent bên ngoài qua AMBA ACE. Thư mục RTL tương ứng chưa triển khai, nên thư mục này cố ý để trống.

## Notes / Lưu ý

- Verification of the current product is in [`verification/non_coherence_cluster`](../non_coherence_cluster/) (64-bit) and [`verification/rv32_profile`](../rv32_profile/) (32-bit and 64-bit). / Kiểm chứng sản phẩm hiện tại nằm ở hai thư mục này.
- Add content here only together with an approved ACE TOP specification. / Chỉ thêm nội dung khi đã có đặc tả TOP ACE được duyệt.
